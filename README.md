> 本分支：[AntsandIce/NcmGaplessPlayer](https://github.com/AntsandIce/NcmGaplessPlayer)（3.1.x）

# GaplessPlayer · 3.1.x 分支

一个 [BetterNCM](https://github.com/std-microblock/BetterNCM) 插件：把「下一首」提前排到
「这一首」的最后一个采样上，切歌间隙压到 **0**。

本文件只记**和上游的差别**，以及本分支**新增 / 修复**了什么。
装法、开关、缓存、响度、排错等使用细节都在 **[docs/GUIDE.md](docs/GUIDE.md)**。

---

## 一、和原作者的差别

| | 上游（Ehytr） | 本分支 |
|---|---|---|
| 支持的客户端 | 2.10.x | **2.10.x 原样 + 3.1.x**（实测 3.1.42.205594） |
| 调度方式 | 预载命中 → 采样级预约 | 同上游，**另加**窗口/预算/预测信任等一整套边界 |
| 接口取址 | 只走 `LibEAPIRequest` | 走它，**并加 3.x 免签名接口兜底**（拿不到退 128k） |
| 首尾裁剪 | 有 | 有，**并把「编码器填充」和「作品静音」分层**（后者默认不裁） |
| 交叉淡入淡出 | 无 | **有**（开关，默认关 = 干净） |
| 拍点/BPM 分析 | 无 | **有**（自带分析；v1.10.0 起**离线缓存**，流式 A 也能对齐；WSOLA 保音高贴拍 ±6%） |
| 缓存 | 内存 | 内存 **+ 磁盘字节缓存** + **拍点/能量离线缓存**（清内存/重启不冷启动） |
| 响度 | 无 | **有**（按曲目拉平，相对中位数，整体音量不变） |
| 界面 | 无 | **有**（播放器栏「♪」→ 设置面板） |
| 流式路径 | 无（只做预载命中） | **有**（`<audio>` 兜底、流式补缓冲、双元素流水线） |

## 二、新增（按版本，只列看得见的）

- **3.1.x 支持**：客户端事件时序不同（`setCurrentPlay` / `load` / `end` 错位），需重排接管逻辑
- **真无缝**：`start(when, offset, duration)` 采样级预约；预载命中时接缝 0ms
- **首尾裁剪**：MP3 priming/padding 按波形验过再裁；「作品静音」单独一个开关（默认不裁）
- **预载 + 预取**：当前曲 → 下一首（解码就绪）→ 下下一首（只抓字节）；下载按优先级**串行**
- **磁盘字节缓存**：`C:\betterncm\gapless-cache`（默认 300MB）；清内存/重启都不再冷启动
- **流式补缓冲**：流式听过的歌补成缓冲，切回来不再重新拉流
- **交叉淡入淡出**（v1.3.0 起，v1.9.4 简化成一个开关）：曲线 / 可选高通扫频
- **拍点分析**（v1.5.0 起）：BPM + 锚点；交叉起点吸拍、时长量化到整拍、B 入点落乐句头、WSOLA 保音高贴拍（±6%）
- **拍点/能量离线缓存**（v1.10.0）：算过的头窗/尾窗/能量落盘成 `analysis.json`（一首约 400 字节），
  和音频缓存解耦 —— 流式 A 没有 AudioBuffer 时也能拿到 BPM，交叉不再退成固定 3 秒
- **补算**（v1.11.0）：空闲时把「盘上有字节、没分析过」的歌一首首读盘→解码→分析（不下载、不占缓冲），
  串行、每首间隔 2s、每会话 ≤30 首；坏字节记 `skip`，不反复重试
- **多窗融合**（v1.12.0）：补算时对头/中/尾三窗各算一次，八度折算后取中位数、按一致性加权置信；
  某一窗测歪（自由节奏前奏 / 加花段）会被另外两窗拉回来，锚点借可信窗外推
- **状态行动态化 + 总开关**（v1.13.0）：`过渡=` 从「只报设定值」改成「设定 + 本次真实值」
  （实际时长/档位/拍数/A→B BPM/A 提前收尾/拉伸）；面板最上面加「插件启用」总开关（关掉 = 整条交回原生）
- **智能交叉**（v1.14.0）：开关一开就按 A 的小节定时长（full 2 小节 / smart 1 小节，夹 2~10s）、
  按档位选曲线（full `r_s-line` / smart `s-line` / plain `equal`）；显式秒数或曲线永远优先；
  面板重做（顶部大号「本次交叉」+ 时长步进器）
- **面板补全**（v1.15.0）：曲线循环 / 扫频 / A 提前收尾 / 首尾裁剪 / 响度参考 / 磁盘缓存 /
  分析记录（含清分析）/ 分析缓存 / 空闲补算全部进面板，开关与控制台变量双向同步
- **面板再收**（v1.16.0）：过渡/音色/缓存三个 Subtab；缓存页只留三项；智能模式下时长不再显示假 3.0s
  （点「固定」才进显式秒数）；插件启用移到关闭按钮左边；面板贴窗口左侧、播放器上方
- **跳过交叉**（v1.17.0）：任一侧没网格 / 置信 <0.1 / 两边都可信但速度差 >6% → 不做交叉，
  只留 20ms 极短淡（不再用 3 秒糊两个不相干的节奏）；状态行与大卡写明原因
- **置信度体检**（v1.17.0）：`gaplessPlayer.audit()` 读现有记录，`audit(true)` 重算三窗
- **A 尾窗两窗**（v1.18.0）：A 的尾窗取「最后 22s + 结尾前 10s 起 20s」，一致融合、不一致取高置信；
  plain 回退不再折拍
- **B 头窗两窗**（v1.20.0）：头窗取「开头 20s + 第 8s 起 20s」，长前奏不再把 BPM/相位带偏
- **连续母带**（v1.19.0）：两边都断在音乐里（无淡出/无静音/电平接得上）→ 保持 0s 原样，
  不交叉、不早收、不跳入点；`__gpKeepContinuous = false` 可关
- **中间地带收紧**（v1.20.0）：偏差 >6% 就跳过（不再要求两侧置信都够）；面板加
  「差拍跳过」「无缝专辑原样」两个开关
- **A 提前收尾**（v1.9.2）：在 outro 掉点/乐句头处就结束 A（最多 8s），而不是「放完了才开始淡」
- **响度平衡**（v1.9.0 起、v1.9.3 重做）：按曲目拉平，**相对本库中位数**，整体音量不变
- **设置面板**（v1.4.0 起、v1.9.4 简化）：按钮在**播放器栏「随机播放」左边**；面板只有开关键 + 缓存
- **诊断接口**：`gaplessPlayer.predict() / beatGrid() / loudness() / diskStats()` 等（见 GUIDE）

## 三、修复（本分支，都是真机日志定位的）

| 版本 | 症状 | 原因 |
|---|---|---|
| 1.8.7 | 手选下一首后，本来能无缝的接缝被放弃 | 把「用户跳歌」当成「随机播放押不中」→ 改成看「上一首是否播完」 |
| 1.8.6 | 连点「下一首」后预载永久关闭 | 同上（`hitStreak` 被清零后再也不敢预约） |
| 1.8.5 | 磁盘缓存「0 首」却毫无日志 | 落盘只认 `slot.trusted`，且失败无日志 → 开机自检 + 跳过原因 + 声明大小兜底 |
| 1.8.4 | 清内存/重启后第一首冷启动很慢 | 没有磁盘缓存；清完也不重排预热 → 新增磁盘层 + 清完立刻重排 |
| 1.8.3 | 交叉时「最后几秒声音被拉得极低」 | 复用的增益节点还留着上一轮的淡出曲线 → 绑定时复位 |
| 1.8.2 | 交叉落在 B 的空白/半拍上 | 没有入点选择 → 跳空白 + 落第一拍/乐句头 |
| 1.9.2 | `bpm` 测对了却「置信 0.00」，贴拍/变速从不生效 | 置信度比「全局均值」被满场 onset 拉平；瞬态密度一票否决 → 改双对比度 + 相位显著性 + 覆盖率 |
| 1.9.3 | 响度平衡「完全用不了」（个别歌被压 12 dB、其它不动） | 直接把接口给的增益当增益施加 → 改「相对本库中位数」，并补 `volumeDelta`/RMS 兜底 |
| 1.9.4 | 面板按钮在右下角、和播放器没关系；面板项太多看不懂 | 按钮改挂到「随机播放」左边；面板只留开关 + 缓存；**过渡风格三档撤掉，只留干净 + 一个开关** |
| 1.10.0 | 交叉永远是「最后 3 秒 / 开头 3 秒」，BPM 检测从不生效 | 流式 A 没有 AudioBuffer → `beatTail` 返回 null → 退 plain；且 `beatGridNear` 先要 buffer 才查缓存 → 新增 `analysis.json` 离线缓存 + 缓存优先 |
| 1.11.0 | 装上新版后，以前缓存的歌仍然没有拍点 | 记录只在解码时产生；盘上旧字节/预取字节从没解码过 → 新增空闲「补算」队列 |
| 1.12.0 | 某一窗测歪就整首不对齐（自由节奏前奏 / 加花尾段） | 单窗无法自证对错 → 补算改三窗融合（中位数 + 一致性加权，锚点借可信窗外推） |
| 1.13.0 | 面板只显示设定的 3.0s，看不出实际过渡发生了什么 | 状态行改成「设定 + 本次真实值」；并加「插件启用」总开关 |
| 1.14.0 | 交叉永远 3 秒、曲线永远 equal，跟拍子无关 | 开关改成「智能」：按小节定时长、按档位选曲线；显式设置仍优先 |
| 1.15.0 | 面板看似完整，实际只有一半设置能调（其余只能控制台） | 曲线/扫频/A 收尾/首尾裁剪/响度参考/磁盘/分析/补算全部进面板，并与控制台双向同步 |
| 1.16.0 | 面板太杂、位置挡控件、智能模式却显示 3.0s | 分三个 Subtab；缓存只留三项；智能模式只写「按小节」；贴窗口左侧；总开关进标题栏 |
| 1.16.1 | 「为什么还是基于 3.0s？」 | plain 档没退回秒数（吃了 2 小节）；状态行摆兜底 3.0s；调度日志曲线写错 → 三处都修 |
| 1.17.0 | 低置信/节奏差也硬做 3 秒交叉，两个节奏打架 | 自动「跳过交叉」（20ms 极短淡）；新增 `audit()` 置信度体检 |
| 1.18.0 | A 的尾窗固定最后 22s，提前收尾后常落在淡出段 | 尾窗取两窗（最后 22s + 往前 10s），一致融合/不一致取高置信；plain 回退不折拍 |
| 1.19.0 | 无缝专辑被智能交叉毁掉衔接（叠淡入淡出、吃掉尾音） | 连续母带检测：无淡出/无静音/电平接得上 → 保持 0s 原样 |
| 1.20.0 | 中间地带（conf 0.1~0.2）仍做 3s 交叉，实际偏差 13~28% | 偏差 >6% 就跳过；面板加两个开关；日志去重 |
| 1.20.0+ | 扫频默认关、差拍跳过默认开；曲线只能循环；时长只能 ±0.5 且切固定跳回 3.0；流式手选后不预约 | 扫频默认开/差拍默认关；曲线 Dialog；时长滑杆 0.1s + 记住上次值；过渡分上下；随机模式按预载放行 |

## 四、安装（详见 GUIDE）

1. 到 **[Releases](https://github.com/AntsandIce/NcmGaplessPlayer/releases)** 下载 `gapless-player-*.plugin`；
2. 可选依赖 **`LibEAPIRequest.plugin`**（建议一起下：不装则 2.10.x 取不到地址 → 退化成纯流式）；
3. 两个 `.plugin` 丢进 `C:\betterncm\plugins\`，重启网易云。

装好不用点播放、不用改快捷方式；插件自己接管。**播放器栏「随机播放」左边那颗 ♪** 打开设置面板。
